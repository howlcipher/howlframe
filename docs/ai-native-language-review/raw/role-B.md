## Your specialized role: B — Security / capability red team
Focus: try to break "intent is not authority". Audit every path by which a program can cause an external effect (network, filesystem, process, environment, database, model/LLM calls, stdin/stdout/stderr, time, exit) in the bytecode VM (-run-bc), the AST interpreter (-run), and generated Go/JS. For each opcode/construct, check whether the capability gate is actually enforced before the effect. Look for fail-open defaults, unchecked opcodes, runtime code generation, grant inheritance by child tasks/agents, artifact tampering, resource exhaustion beyond instruction counts (memory, wall-clock, output size), and TOCTOU. Where feasible, PROVE findings by building the CLI and running tiny programs under /tmp (you may start a local dummy HTTP listener on 127.0.0.1 to observe outbound requests). Rank findings by severity with repro steps.
