## References and how to run them
- cli_app semantics: the bytecode VM. Run it with `howlframe prog.howl`; this also
  writes prog.hfbc into the working directory. The VM stops at 100,000 instructions by
  default; for big programs use `howlframe run --max-instructions 500000000 prog.howl`.
  The VM exits the process on runtime errors, so tests run it as a subprocess.
- Browser host operations and `test` blocks: there is no VM runner for tests. The
  JavaScript backend is the reference: `howlframe build t.howl --target js -o DIR`,
  then `node --test DIR/app.test.js`, or `node DIR/app.js` for a program.
  HowlScene HF runs its core tests with scripts/test_core.sh, which does exactly that.
- Compare against Go 1.25 behavior. Where newer Go changes stdlib text, the VM must own
  the text (as json_text.go does), not skip the test.

## Method (every slice)
- Probe the reference with small programs before writing code.
- Work test-first. Add differential fixtures for the happy path, errors and edge cases.
- Check that each fixture is not vacuous: the reference must run and print what it
  should. Prove that a regression test fails without the fix by reverting the source
  files, then restore them.
- Validate every module with `wasm-tools validate --features all`. Node validates
  lazily.
- Fail closed: an unsupported construct gives WASM_UNSUPPORTED with a source location.
  Never emit wrong code silently.
- A bug in the VM or another backend gets its own branch and PR, with a bugs.md entry
  (ranked row plus details section) and a regression test.
- Host imports stay typed and capability-gated. No JS beyond generated loaders and
  runners.

## Traps found in M1
- Escape sequences: a literal backslash-u plus four hex digits in text you write through
  a tool can arrive as the decoded character. This corrupted a Go raw string and a JSON
  escape table. Build such text from parts (for example `` `\` + "u" ``, or byte
  literals like '\\', 'u'), or generate files with a script that uses a placeholder
  for the backslash. Then grep the file for raw U+FFFD or other decoded characters.
- gofmt realigns map literals, so exact-text replacements in edit scripts miss after
  formatting. Match by key or line instead.
- Merges: when two branches add functions at the same spot, git can give the shared
  closing braces to one side only. After resolving "keep both", run `go vet` and fix
  the seam. Resolve bugs.md rows by taking the "Done" row from whichever side has it.
- Branch protection requires branches to be up to date with main: use
  `gh pr update-branch N` or merge origin/main, then rerun the gate.
- The checker rejects mixed-type lists and some literals, for example `(list 1 2.5)`
  and `1e30` (write 1000000000000000000000000000000.0). Values of unknown type come
  from a dict with mixed values, as the `mixed` fixture constant does.
- Use `run_in_background` for the full gate (about 4–5 minutes) and wait for its
  notification. Never commit or open a PR from a chain that does not check the gate's
  exit status.
