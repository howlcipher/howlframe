# AI-DX2 measurement preregistration
Frozen before implementation, 2026-11-09. Baseline 358fe92acf320460af022ea62d10644fb968f342; treatment is eventual merged AI-DX2 revision. No efficiency result claimed.
Compare matched clean recovery, dirty source recovery, dependency/config/test edits, altered/missing evidence, and interruption during verification. Use identical disposable Git fixtures, fixed toolchain versions recorded before trials, equal model/tool budgets, randomized paired order with recorded seed, and held-out correctness checks. Interrupt after edit, during execution, and after evidence publication. Retain all failed attempts.
Measure each task separately: all input/output/tool context, command count, repair payload, snapshot creation, recovery, evidence maintenance, invalidation/reverification costs, elapsed time and correctness. Report per-task pairs, failures and dispersion. Correctness and reliable resumption must not regress. Targets of 50% resume context, 30% maintenance tokens and 20-25% total time remain hypotheses. Live-agent trials deferred pending verified no-payment route. Deterministic acceptance cannot establish savings.
