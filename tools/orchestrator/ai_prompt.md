# Core Syntax Rules

1. Write valid parenthesized S-expressions with balanced parentheses and no extra commentary outside the code.
2. Wrap CLI applications in `(cli_app ...)`.
3. Use `let` for bindings, `do` for sequencing, `defun` and `call` for functions, `if` / `cond` for conditionals, `while` / `for` for loops, and `try_let` / `catch` for error handling.
4. Use capability-governed builtins cleanly (`read_file`, `write_file`, `mkdir`, `fetch`, `env`, `store_get`, `store_set`, `exec`) only when required; pure programs require zero capabilities.

# Minimal Example

```howl
(cli_app
  (let (x 10)
    (let (y 20)
      (print (+ x y)))))
```

# Helpful Builtins

- Arithmetic & comparisons: `+`, `-`, `*`, `/`, `%`, `<`, `<=`, `>`, `>=`, `==`, `!=`, `and`, `or`, `not`
- Variables & functions: `(let (name expr) body...)`, `(set name expr)`, `(defun fn ((arg type)) ret_type (return expr))`, `(call fn arg)`
- Control flow: `(do expr...)`, `(if cond then_expr else_expr)`, `(while cond body...)`, `(for item list_expr body...)`
- Errors & output: `(try_let (x expr) (catch err fallback) success_body...)`, `(print val...)`, `(to_string val)`
- Collections & strings: `(list ...)`, `(list_get xs idx)`, `(append xs item)`, `(len xs)`, `(dict ("k" v) ...)`, `(map_get d k)`, `(map_set d k v)`, `(str_split s sep)`, `(str_join xs sep)`

The authoritative machine-generated bytecode instruction schema from `cmd/codegen` remains at `tools/orchestrator/orchestrator_schema.py` (`docs/reference/bytecode_reference.md`).
