## Additional deliverable: diagnostic-quality rubric

Write `pool/DIAGNOSTIC_RUBRIC.md`. Blind graders will see the first compiler or runtime error message an agent hit
(language name hidden where possible) and score it 1 to 5. Define each score with observable criteria (does it name
the file and line; does it state what was expected and what was found; does it suggest a fix; is it accurate), give one
short invented example per score in a neutral pseudo-language, and state tie-break rules. It must not favour any
language's error style.
