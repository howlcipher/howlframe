# Release Authority

Demonstrates an untrusted AI proposing deployment actions while standalone HowlFrame independently enforces evidence, approval, capability, and state-transition policy.

## Security Disclaimer

This is an experimental authority-boundary demonstration.

Do NOT claim or expect:
* sandbox isolation equivalent to containers/VMs
* production security
* formal verification unless actually formal
* protection against every prompt injection
* autonomous production deployment
* production-ready policy enforcement
